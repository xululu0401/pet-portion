# 粮喂多了（pet-portion）

猫狗每天到底该喂多少克粮、几个罐头；四套喂法并排看月花费；到目标体重要多少周。

单文件应用：`index.html` 里同时打包了引擎（`core.js`）与界面（`ui.js`）。不联网、不上传任何数据、不认品牌。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 成品（构建产物，可直接双击打开） |
| `template.html` | 页面骨架与样式，含 `/*CORE*/`、`/*UI*/` 两个占位符 |
| `core.js` | 计算引擎（纯函数，浏览器与 node 通用，挂 `window.AppCore`） |
| `ui.js` | 界面层：读写 DOM、四套方案对照表、四种导出、本机存档 |
| `build.cjs` | 把 core.js / ui.js 注入 template.html 生成 index.html |
| `tests/core.test.cjs` | 核心测试：`node --test tests/core.test.cjs` |
| `make-cover.cjs` | 生成 1200×1200 封面（数字取自同一次引擎输出） |
| `cover.png` | 封面 |

## 口径（与页面、说明里的数字同一套）

```
RER       = 70 × 体重^0.75                    （kcal/日）
MER       = RER × k                           （k 按物种/年龄阶段/绝育/活动量查表）
体脂率     = 分档表[BCS]；去脂体重 = 体重 × (1 − 体脂率)
理想体重   = 去脂体重 ÷ (1 − 20%)              （去脂体重守恒）
干粮 g    = 干粮热量 ÷ (干粮 kcal/100g) × 100
罐头 罐    = 湿粮热量 ÷ (罐头 kcal/100g × 罐净重 ÷ 100)
减重缺口   = 速率 × 体重 × 7700 ÷ 7            （猫 0.75、狗 1.5 %体重/周）
目标热量   = max(MER − 缺口, max(0.8 × RER(理想体重), 0.6 × MER))
实际速率   = (MER − 目标热量) × 7 ÷ 7700 ÷ 体重 × 100
周数       = (体重 − 目标体重) ÷ 体重 × 100 ÷ 实际速率
月成本     = 每日 g × 30 ÷ 1000 × 元每kg + 每日罐数 × 30 × 元每罐
1000 kcal 单价：干粮 = 10 × 元每kg ÷ (kcal/100g)；罐头 = (1000 ÷ kcal每g) ÷ 罐净重 × 元每罐
```

体况评分到体脂率是**分档设计表**（1→5%、5→20%、7→35%、9→55%）；速率系数取自公开兽医营养资料里常见的区间中值，是设计选择，不是唯一正确答案。

## 边界（页面上也写着）

只做算术：**不做诊断、不开处方、不评价粮的品质与配方**。不处理疾病、处方粮、怀孕哺乳期、需要个体化方案的肥胖症治疗、生骨肉／自制粮的营养均衡性判断。目标体重不小于当前体重时不排减重时间线。

默认数据是**虚构示例**，不是任何真实用户、品牌或价格分布。
